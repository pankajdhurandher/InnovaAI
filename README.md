# InnovaAI   
_Innovation + AI in one place_

InnovaAI is an AI-powered productivity platform that brings multiple creative and analytical tools into a single dashboard.  
From generating blogs and images to cleaning backgrounds, reviewing resumes, and tracking content performance – InnovaAI is built to help students, professionals, and creators work smarter.

---

##  Key Features

- 📝 **Blog Generation**  
  Generate high-quality, SEO-friendly blog articles from simple prompts or topic ideas.

- 🖼️ **Image Generation**  
  Create AI-generated images for blogs, social media, and projects based on text descriptions.

- 🪄 **Object Removal**  
  Upload an image and remove unwanted objects cleanly using AI-powered inpainting.

- 🧼 **Background Removal**  
  One-click background removal for product photos, profile pictures, and designs.

- 🧾 **Version Control for Generated Content**  
  - Track different versions of generated blogs, images, and assets  
  - Restore previous versions  
  - Compare changes over time  

- 📊 **Analytics Dashboard**  
  - Monitor usage stats (number of generations, feature usage, etc.)  
  - Track performance metrics like word count, content categories, etc.  
  - Visual overview to understand how InnovaAI is being used

- 📄 **Resume Review & Scoring**  
  - Upload your resume and get AI-powered feedback  
  - Get a score based on readability, keywords, tech stack, and role fit  
  - Suggestions to improve formatting and content

- 🌐 **Community Interaction**  
  - Like, comment, or share AI-generated content (if enabled)  
  - Learn from how others prompt and use AI  
  - Optional public community feed

- ✅ **Plagiarism & Originality Checker**  
  - Check generated blogs or text for originality  
  - Highlight potentially similar content  
  - Help maintain originality in assignments, blogs, and articles
