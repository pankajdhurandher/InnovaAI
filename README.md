# InnovaAI   
_Innovation + AI in one place_

InnovaAI is an AI-powered productivity platform that brings multiple creative and analytical tools into a single dashboard.  

---

##  Key Features

- 📄 **Resume Review & Scoring**  
  - Upload your resume and get AI-powered feedback  
  - Get a score based on readability, keywords, tech stack, and role fit  
  - Suggestions to improve formatting and content
